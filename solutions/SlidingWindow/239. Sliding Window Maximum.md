# LeetCode 239. Sliding Window Maximum (Hard)

## 1. 題目解析
題目要求在給定的整數陣列 `nums` 中，找出每個大小為 `k` 的滑動視窗（Sliding Window）在向右移動時的**最大值**，並依序將其組成一個陣列回傳。

* **輸入：** `nums = [1, 3, -1, -3, 5, 3, 6, 7]`, `k = 3`
* **輸出：** `[3, 3, 5, 5, 6, 7]`
* **核心難點：** 如何在滑動視窗移動時，以 $O(1)$ 的時間複雜度動態獲取當前區間的最大值，避免每次移動都重新遍歷。

---

## 2. 核心演算法與資料結構
本題的最佳解法為 **單調隊列（Monotonic Queue）**，在實作上利用 **雙端隊列（Deque）** 來達成。

* **單調雙端隊列（Monotonic Deque）：** 隊列內部的元素對應的數值必須維持「由大到小」的**單調遞減性**。
* **儲存內容：** 隊列中應儲存元素的**「索引（Index）」**而非數值。這樣能透過索引輕易判斷隊首的最大值是否已經超出當前滑動視窗的左界。

---

## 3. 解題思路與方法比較

### 方法一：暴力法 (Brute Force)
* **思路：** 每次視窗移動，就遍歷視窗內的 `k` 個元素找出最大值。
* **時間複雜度：** $O(N \times k)$ -> 會導致 **TLE (Time Limit Exceeded)**。
* **空間複雜度：** $O(1)$。

### 方法二：最大堆積 (Max-Heap / Priority Queue)
* **思路：** 將元素與索引存入 Max-Heap。每次移動視窗，加入新元素並檢查堆頂的最大值是否過期（超出視窗左界），若過期則彈出。
* **時間複雜度：** $O(N \log N)$（最差情況下 Heap 會增長到與 $N$ 相同大小）。
* **空間複雜度：** $O(N)$。

### 方法三：單調雙端隊列 (Monotonic Deque) ⭐ 最佳解
* **思路：** 1. **維持單調性：** 新元素準備從隊尾進入時，若它大於或等於隊尾元素，代表舊隊尾在未來絕不可能成為最大值，將舊隊尾彈出。重複此步驟直到滿足單調遞減，再將新元素索引放入隊尾。
  2. **移除過期元素：** 檢查隊首的最大值索引是否小於當前視窗左界 `i - k + 1`，若是則將隊首彈出。
  3. **記錄答案：** 當視窗完全形成（`i >= k - 1`）時，隊首索引對應的數值即為當前視窗最大值。
* **時間複雜度：** $O(N)$（每個元素最多進出隊列各一次）。
* **空間複雜度：** $O(k)$（隊列最多同時存在 `k` 個元素）。

| 方法 | 時間複雜度 | 空間複雜度 | 缺點/優點 |
| :--- | :--- | :--- | :--- |
| **暴力法** | $O(N \times k)$ | $O(1)$ | 效率太低，大測資會超時 |
| **最大堆積** | $O(N \log N)$ | $O(N)$ | 稍微慢了點，但好理解 |
| **單調隊列** | $O(N)$ | $O(k)$ | **最佳解**，時間與空間效率最高 |

---

## 4. 實作流程與步驟
1. **初始化：** 建立雙端隊列 `queue = deque()` 儲存索引，與結果陣列 `result = []`。
2. **迭代遍歷：** 用指標 `i`（視窗右界）遍歷整個 `nums` 陣列：
   * **步驟 A (清隊尾)：** 當隊列不為空且當前元素 `nums[i] >= nums[queue[-1]]` 時，將隊尾彈出（維持單調遞減）。
   * **步驟 B (入隊尾)：** 將當前索引 `i` 加到隊尾。
   * **步驟 C (清隊首)：** 若隊首索引 `queue[0] < i - k + 1`，代表其已滑出視窗，將隊首彈出。
   * **步驟 D (記答案)：** 當 `i >= k - 1`（視窗成形），將當前隊首 `nums[queue[0]]` 加入 `result`。
3. **回傳結果：** 遍歷結束後回傳 `result`。

---

## 5. 常見錯誤與陷阱
1. **隊列中誤存「數值」而非「索引」：** 若存數值，當陣列中出現重複數字，或需要判斷左邊界元素是否過期時，會無法準確定位。**務必儲存 `index`**。
2. **邊界條件判定錯誤：** 移除過期隊首的臨界點為 `i - k + 1`。另外，必須等到 `i >= k - 1` 才能開始將答案寫入 `result`，否則前幾步視窗尚未完整。
3. **忘記使用 while 迴圈：** 在清空隊尾比當前小的元素時，必須用 `while queue and ...` 將所有較小元素移除，誤用 `if` 只會移除一個，進而破壞單調性。
