# LeetCode 91. Decode Ways 筆記

## 1. 題目解析
本題要求計算一個由數字組成的字串 `s` 有多少種合法的字母解碼方式。
*   **解碼規則**：'1' -> 'A', '2' -> 'B', ..., '26' -> 'Z'。
*   **限制條件**：
    *   '0' 不能獨立被解碼（沒有 '0' 對應的字母）。
    *   '0' 必須與前面的數字結合（如 '10' 或 '20'），若出現 '30' 或開頭為 '0' 則無效。
    *   組合出的數字必須落在 1 到 26 之間。

## 2. 核心演算法與資料結構
*   **演算法**：**動態規劃 (Dynamic Programming)**。
*   **資料結構**：一維 DP 陣列（空間複雜度 $O(n)$），或使用兩個變數進行空間優化（空間複雜度 $O(1)$）。
*   **狀態定義**：`dp[i]` 表示字串 `s` 前 `i` 個字元的解碼總數。

## 3. 解題思路與方法比較
### 動態規劃法 (Bottom-up)
1.  **初始化**：
    *   `dp[0] = 1`：空字串解碼數為 1（作為雙位數解碼成功的基準值）。
    *   `dp[1] = 1`：已知 `s[0]` 不為 '0' 時，首位數字僅有一種解法。
2.  **狀態轉移**：
    *   **個位數檢查**：若 `s[i-1]` 不為 '0'，表示當前數字可獨立解碼，累積 `dp[i-1]`。
    *   **雙位數檢查**：若 `s[i-2...i-1]` 組成的數字介於 10 與 26 之間，表示當前數字可與前一位結合，累積 `dp[i-2]`。
3.  **優缺點**：
    *   相較於遞迴（Top-down），DP 避免了重複計算，時間複雜度為 $O(n)$。

## 4. 常見錯誤與陷阱
*   **'0' 的處理**：
    *   字串開頭為 '0'：直接回傳 0。
    *   中間出現 '0'：例如 '10' 或 '20' 是合法的，但 '30', '40' 或 '00' 會導致整個解碼路徑中斷（該路徑 `dp` 值為 0）。
*   **索引偏移 (Off-by-one)**：
    *   `dp[i]` 長度為 `n+1`，對應字串 `s` 的索引為 `s[i-1]`。
    *   雙位數切片為 `s[i-2:i]`。
*   **進位溢位**：雖然這題結果通常在整數範圍內，但在某些語言中需注意結果是否過大（Python 則不需擔心）。
