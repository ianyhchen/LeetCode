# LeetCode 72. Edit Distance 筆記

## 1. 題目解析

給定兩個字串 `word1` 與 `word2`，計算將 `word1` 轉換成 `word2` 所需的**最少操作步驟數**。
允許的三種字元操作：
1. **插入 (Insert)** 一個字元
2. **刪除 (Delete)** 一個字元
3. **替換 (Replace)** 一個字元

### 範例分析
* **輸入：** `word1 = "horse"`, `word2 = "ros"`
* **輸出：** `3`
* **步驟說明：**
  1. `horse` -> `rorse` (將 'h' 替換為 'r')
  2. `rorse` -> `rose` (刪除 'r')
  3. `rose` -> `ros` (刪除 'e')

---

## 2. 核心演算法與資料結構

* **核心演算法：** **動態規劃 (Dynamic Programming, DP)**
  * 本題具有「重疊子問題」與「最優子結構」特點，藉由記錄子問題的解答來避免重複計算。
* **狀態定義：**
  * 定義二維陣列 $dp[i][j]$ 代表將 `word1` 的前 $i$ 個字元轉換成 `word2` 的前 $j$ 個字元所需的最少操作數。
* **資料結構：**
  * **二維 DP 表 (2D Array)：** 大小為 $(M + 1) \times (N + 1)$，其中 $M$ 與 $N$ 分別為兩字串長度。

---

## 3. 解題思路與方法比較

### 狀態轉移方程推導

比較 `word1[i-1]` 與 `word2[j-1]`（第 $i$ 個與第 $j$ 個字元）：

1. **若字元相同 (`word1[i-1] == word2[j-1]`)：**
   不需要任何操作，直接繼承前一步狀態：
   $$dp[i][j] = dp[i-1][j-1]$$

2. **若字元不同 (`word1[i-1] != word2[j-1]`)：**
   必須在以下三種操作中選擇最少步驟者，並加上本次操作的 $1$ 步：
   * **替換 (Replace)：** 同時退回一格 $\rightarrow dp[i-1][j-1] + 1$
   * **刪除 (Delete)：** 丟棄 `word1[i-1]` $\rightarrow dp[i-1][j] + 1$
   * **插入 (Insert)：** 在 `word1` 後補上與 `word2[j-1]` 相同的字元 $\rightarrow dp[i][j-1] + 1$
   
   $$dp[i][j] = \min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]) + 1$$

### 方法比較

| 方法 | 時間複雜度 | 空間複雜度 | 特點 |
| :--- | :--- | :--- | :--- |
| **遞迴 + 記憶化 (Top-Down)** | $O(M \times N)$ | $O(M \times N)$ | 直觀，但遞迴過深可能有 Stack Overflow 風險。 |
| **二維 DP (Bottom-Up)** | $O(M \times N)$ | $O(M \times N)$ | **推薦面試解法**。結構清晰，好實作且易於除錯。 |
| **一維 DP (空間優化)** | $O(M \times N)$ | $O(\min(M, N))$ | 極致優化，但需額外變數暫存左上角的值，代碼較難維護。 |

## 5. 常見錯誤與陷阱

1. **二維陣列宣告的行列對調 (重要！)：**
   * Python 宣告 `m + 1` 列、`n + 1` 欄的正確寫法為：
     `dp = [[0] * (n + 1) for _ in range(m + 1)]`
     若寫成 `[[0] * (m + 1) for _ in range(n + 1)]` 會導致行、列大小顛倒，在後續以 `dp[i][j]` 存取時會噴出 `IndexError`。
2. **忘記初始化 Base Case (第一行與第一列)：**
   * 必須先填補好其中一個字串為空字串時的基礎步數：
     * $dp[0][j] = j$ (全插入)
     * $dp[i][0] = i$ (全刪除)
3. **字串與 DP 表索引混淆：**
   * 因為 DP 表多預留了長度 0 的空間，所以在比較字元時，`word1` 的第 $i$ 個字元對應的是 `word1[i-1]`，同理 `word2` 對應 `word2[j-1]`。
