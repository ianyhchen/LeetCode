# LeetCode 210. Course Schedule II 筆記

## 1. 題目解析
- **核心目標**：給定課程總數與先修依賴關係，回傳一個可以完成所有課程的修課順序。若無法完成（存在循環依賴），則回傳空陣列。
- **圖論建模**：
    - **節點 (Nodes)**：課程編號 $0$ 到 $n-1$。
    - **有向邊 (Edges)**：若修 `a` 前需先修 `b`，則存在一條 $b \to a$ 的邊。
    - **合法條件**：該圖必須是一個 **DAG (有向無環圖)**。

## 2. 核心演算法與資料結構
- **演算法：Kahn's Algorithm (基於 BFS 的拓撲排序)**
    - 透過維護節點的「入度」(In-degree) 來決定處理順序。
- **資料結構**：
    - **鄰接表 (Adjacency List)**：`graph = [[] for _ in range(numCourses)]` 用於儲存圖。
    - **入度表 (In-degree Array)**：`in_degree = [0] * numCourses` 記錄每個節點被多少條邊指向。
    - **佇列 (Queue/Deque)**：存放入度為 $0$ 的節點（即當前可以直接修讀的課程）。

## 3. 解題思路與方法比較
### 思路步驟：
1. **建立圖與計算入度**：遍歷 `prerequisites`，建立鄰接表並累計每個節點的 `in_degree`。
2. **初始化佇列**：將所有 `in_degree == 0` 的節點放入 `queue`。
3. **BFS 處理**：
    - 從 `queue` 取出一個課程，加入結果清單 `order`。
    - 遍歷該課程的所有鄰居（後續課程），將其入度減 $1$。
    - 若某鄰居入度變為 $0$，將其加入 `queue`。
4. **判斷環**：若 `order` 中的課程數量等於 `numCourses`，則回傳 `order`；否則回傳 `[]`。

### 方法比較：
- **Kahn's (BFS)**：直觀，適合產出字典序或按層級處理，易於偵測環（最後檢查計數）。
- **DFS**：利用遞迴標記狀態（0:未訪, 1:訪問中, 2:已訪），程式碼較簡短但需注意遞迴深度與結果反轉。

## 5. 常見錯誤與陷阱
- **環的偵測**：若最後結果長度小於課程總數，代表圖中有環（Cycle），必須回傳空陣列。
- **入度方向反轉**：務必確認是 `src -> dest` 還是 `dest -> src`，本題為 `prerequisites[1] -> prerequisites[0]`。
- **空間初始化**：必須根據 `numCourses` 初始化鄰接表，因為有些課程可能完全沒有出現在 `prerequisites` 中（孤立節點）。
