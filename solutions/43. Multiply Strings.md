# LeetCode 43. Multiply Strings

### 1. 題目解析
輸入兩個以字串表示的非負整數 `num1` 和 `num2`，回傳它們的乘積（同樣以字串形式）。
*   **關鍵限制：** 不能使用任何內建的大數庫，且不能直接將字串轉成整數（如 `int(num1)`）進行相乘。

---

### 2. 核心演算法與資料結構
*   **直式乘法模擬 (Math Simulation)**：精確模擬小學乘法直式的累加與進位。
*   **位置對應陣列**：宣告一個長度為 $M + N$（$M$, $N$ 分別為兩字串長度）的整數陣列 `res` 來儲存每位數相乘的中間值。

---

### 3. 解題思路與方法比較
#### 關鍵物理規律：
設 `num1` 在索引 $i$ 的數字與 `num2` 在索引 $j$ 的數字相乘（從右至左）：
*   相乘結果 `mul = num1[i] * num2[j]`。
*   該結果的個位數（當前位）應累加至 **`res[i + j + 1]`**。
*   其十位數（進位）應累加至左側相鄰的 **`res[i + j]`**。

| 方法 | 時間複雜度 | 空間複雜度 | 優缺點 |
| :--- | :--- | :--- | :--- |
| **逐行相加 (大數加法輔助)** | $O(M \times N + N^2)$ | $O(M + N)$ | 邏輯直覺，但頻繁處理字串拼接與加法呼叫，常數大且程式碼冗長。 |
| **位置對應陣列累加 (推薦)** | $O(M \times N)$ | $O(M + N)$ | **最佳解**。直接在 `res` 原地處理進位與累加，效率極高，程式碼優雅。 |

---

### 4. 常見錯誤與陷阱
1.  **「0」的邊界處理**：若輸入是 `"0"` 與 `"0"`，未處理可能導致輸出為 `"000"` 或空字串。
2.  **前導零的去除**：乘法完成後，陣列高位常有未填滿的 `0`，必須精準跳過。
3.  **索引對應錯誤**：`i + j + 1` 與 `i + j` 關係容易在編寫時寫反。
