# LeetCode 179. Largest Number 筆記

## 1. 題目解析
本題要求將一組非負整數重新排列，組合成一個「最大的字串」。
* **核心挑戰**：一般的數值排序（降序）無法直接應用，例如 `30` 比 `3` 大，但在組合時 `3` 應該排在 `30` 前面（`330` > `303`）。
* **回傳型態**：必須回傳字串，因為組合後的數字可能遠超 64-bit 整數範圍。

## 2. 核心演算法與資料結構
* **資料結構**：字串陣列 (String Array)。
* **演算法**：自定義排序 (Custom Sorting) + 貪婪演算法 (Greedy Strategy)。
* **工具**：使用 Python 的 `functools.cmp_to_key` 來實作雙元素對接比較。

## 3. 解題思路與方法比較
* **思路**：
    1. 將所有數字轉換成字串。
    2. 定義比較函數：比較 `A+B` 與 `B+A` 的大小。
    3. 若 `A+B > B+A`，則在排序中 $A$ 應位於 $B$ 之前。
    4. 排序後將字串接合，並處理全為 0 的特殊情況。
* **方法比較**：
    * **暴力法**：排列組合所有可能，$O(n!)$，效率太低。
    * **自定義排序**：$O(n \log n)$，為此類問題的最佳解。

## 5. 常見錯誤與陷阱
* **忽略邊界案例**：輸入 `[0, 0]` 時，如果不加處理會得到 `"00"`，正確應回傳 `"0"`。
* **比較邏輯錯誤**：僅比較數字的第一位或長度。例如 `[3, 34]`，若只看首位相同就隨機排，會錯失正確答案。
* **類型報錯**：忘記先將整數轉為字串就進行 `+` 運算，會導致 Python 進行數值加法而非字串對接。
